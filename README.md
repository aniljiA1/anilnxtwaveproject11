# 📸 RiseUpp Image Search App

A responsive ReactJS web application that allows users to search and explore high-quality images using the Unsplash API.

---

# Live Demo
Live: https://anilnxtwaveproject11.vercel.app


---

## 🚀 Live Features

✅ Search images from Unsplash  
✅ Category-based quick search  
✅ Responsive image grid layout  
✅ Hover popup with image details  
✅ Pagination support  
✅ Loading state while fetching data  
✅ Fully responsive design

## ⚙️ Installation

### 1️⃣ Clone Repository

```bash
git clone https://github.com/your-username/riseupp-image-search.git
2️⃣ Navigate to Project
cd riseupp-image-search
3️⃣ Install Dependencies
npm install
4️⃣ Create Environment File

Create .env in root directory.

VITE_UNSPLASH_ACCESS_KEY=YOUR_UNSPLASH_ACCESS_KEY

Get API key from:
https://unsplash.com/developers

5️⃣ Start Development Server
npm run dev
🌐 Unsplash API

This project uses the official Unsplash Search Photos API.

Documentation:
https://unsplash.com/documentation#search-photos
